## A13 — the evidence gap the builder named, and why it closes

The builder could not produce a genuine content-modification to test with: G2
blocks its Edit door, the architect is create-only, and the shell would have
been the bypass. So it staged a **deletion** via `git rm --cached` — git
plumbing, no file written, index restored immediately — and reported honestly
that the true modification case was untestable from inside the cage, calling it
a gap in the evidence rather than in the design.

**The gap closes on the implementation, and only reading it shows that:**

    CHANGED=$(git diff --cached --name-only --diff-filter=MDR -- "$CAMPAIGN")

`M`, `D` and `R` share **one filter feeding one code path**. There is no
separate branch for modification. A staged deletion exercises byte-for-byte the
same logic a modification would. The substitution is not a weaker proxy — it is
the identical branch, and the hook therefore also covers renames, which nobody
ordered and which is the third way to damage a record.

The builder's caution was correct a priori and its worry is retired by the
code. Verified `git diff HEAD -- orders/order-M0.1.md` is empty and the file is
still tracked; nothing was damaged by the test.
