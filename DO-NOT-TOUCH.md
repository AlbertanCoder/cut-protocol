Generated by Phase 0 audit on 2026-08-04. Claude Code must never modify anything

Audit method: every file under `frontend/src` was read in full and classified
PRESENTATION / LOGIC / MIXED by independent reviewers, then adversarially

protected — the owner can loosen entries by hand.

## Always off-limits (categories)

State management, API calls, data fetching, calculations, data transformations,
routing (this app's "router" is the `tab` state machine in `App.jsx`), auth,
storage (localStorage/sessionStorage of app data), env/secrets, CI config, the
entire backend, the Electron shell, the relay service.

Safety-derived UX rules that must survive ANY new visual direction (they are
product/safety decisions, not aesthetics): never red on food or body data
(over-target renders calm amber with supportive copy — ED-safety); the three
macros must remain colorblind-distinguishable and always carry P/C/F letter
labels; the Wellbeing entry and its support resources are never hidden or greyed
out; progress indicators never fabricate percentages; `prefers-reduced-motion`
support and the a11y utilities (`.sr-only`, `.skip-link`, focus rings,
focus traps) must survive.
